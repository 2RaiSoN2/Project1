## 🛠 3. Технічні вимоги та обмеження (Technical Stack & Constraints)

> [!WARNING]
> **Жодних фреймворків чи сторонніх збирачів!** Проєкт розробляється суворо за стандартами чистого ванільного вебу (Vanilla Web).

### 3.1. Дозволений стек
1. **HTML5:**
   - Семантична та валідна розмітка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
   - Обов'язкова мета-інформація (viewport, charset, SEO meta tags).
2. **CSS3:**
   - Чистий Vanilla CSS без препроцесорів та Tailwind CSS.
   - Сучасні методи розкладки: **Flexbox** та **CSS Grid**.
   - Організація стилів через CSS Custom Properties (змінні кольорів, відступів, шрифтів).
   - Адаптивність (Mobile-first, breakpoints для смартфонів, планшетів, десктопів).
3. **JavaScript (ES6+):**
   - Чистий Vanilla JS без зовнішніх бібліотек (без jQuery, React тощо).
   - Модульна організація логіки (події DOMContentLoaded, плавна навігація, інтерактивні фільтри/картки, анімації).

### 3.2. Суворі заборони
- ❌ **Жодних JS-фреймворків** (React, Vue, Angular, Svelte тощо).
- ❌ **Жодних CSS-фреймворків** (Tailwind, Bootstrap тощо).
- ❌ **Жодних складних збирачів** (Vite, Webpack, Parcel тощо).
- ❌ **Жодних інлайн-стилів** (`style="..."`) та інлайн-скриптів у HTML.

## 🎨 4. Дизайн-система та естетика (Design System)

- **Візуальний стиль:** Натхненний естетикою **Avant-Garde & Japanese Archive** — преміальний мінімалізм, атмосферна темна тема, високий контраст, архітектурна геометрія блоків.
- **Колірна палітра:**
  - Фон основний: глибокий вугільний/чорний (`#0a0a0a`, `#0f0f10`).
  - Фон карток та панелей: графітовий/матований (`#161618`, `#1e1e22`).
  - Межі та роздільники: тонкі витончені лінії (`rgba(255, 255, 255, 0.08)` або `#2a2a30`).
  - Основний текст: чистий білий / вибілений (`#ffffff`, `#f3f3f5`).
  - Вторинний текст: приглушений сріблясто-сірий (`#8a8a93`, `#a1a1aa`).
  - Акценти: монохромні градієнти, приглушений платиновий або невагомий неон.
- **Типографіка:**
  - Google Fonts: поєднання сучасного гротеску (*Space Grotesk*, *Inter*, *Syne*) та моноширинного технічного шрифту (*JetBrains Mono*, *Space Mono*) для статистики та коду/треків.
- **UX та мікро-анімації:**
  - Плавний скрол (`scroll-behavior: smooth`).
  - Витончені hover-ефекти для інтерактивних елементів (картки ігор, треки плеєра, посилання).
  - Повна адаптивність під сенсорні екрани (Touch-friendly).

## 🤖 6. Правила та інструкції для моделі ШІ (AI Agent Guidelines)

1. **Мовний протокол:**
   - **Спілкування з користувачем:** виключно українською мовою.
   - **Текстовий контент інтерфейсу сайту:** українською мовою (зі збереженням оригінальних назв ігор, брендів, артистів та треків латиницею: *Fortnite, Dota 2, Yohji Yamamoto, Rick Owens, fakemink* тощо).
   - **Код, назви змінних/класів, коментарі в коді:** англійською мовою за стандартом чистого коду (Clean Code).
2. **Точність та правдивість:**
   - Суворо спиратися на фактичний зміст розділу **2. Вихідні дані та контент**. Не вигадувати нові вигадані захоплення чи фальшиві досягнення.
3. **Якість коду та доступність (Accessibility):**
   - Дотримуватися стандартів семантики (WAI-ARIA, інформативні `alt` для зображень, правильна ієрархія заголовків `<h1>`–`<h3>`).
   - Забезпечити повну адаптивність під мобільні пристрої (перевірка медіа-запитів `@media`).
4. **Формат відповідей:**
   - Надавати зрозумілі, лаконічні та структуровані рішення.
   - При написанні або зміні коду завжди пояснювати ключові рішення та надавати готовий до запуску результат.

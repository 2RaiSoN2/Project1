# Assets Directory

Ця папка призначена для збереження медіа-файлів, іконок, графіки та фотографій проєкту.
Всі основні іконки, монограми та векторні бейджі (Fortnite Unreal, Dota 2 Legend) оптимізовані та інтегровані безпосередньо у векторному форматі SVG для миттєвого завантаження та максимальної чіткості на Retina/4K-дисплеях.
